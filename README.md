# Autoclicker

Un simple autoclicker desarrollado en Python.

## Requisitos

- Python 3.x
- Ver `requirements.txt` para las dependencias.

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/EnzoMartinezX/autoclicker.git
   ```
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

## Uso

Ejecuta el script principal:
```bash
python autoclicker.py
```

## Construcción (Windows)

Para crear un ejecutable, corre el script `build.bat` (asegúrate de tener pyinstaller instalado).
